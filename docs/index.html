Claude Code skill

video‑to‑article

Turn a video into an illustrated article you can actually read — with the speaker's own diagrams dropped in where they are discussed.

What it does

It pulls the subtitles, scans every frame to find the diagrams, charts and slides, cuts screenshots at the moment each graphic is fully drawn, cuts short clips where motion carries the meaning, and assembles a Markdown write-up plus a styled page where those clips play inline.

Works on a YouTube URL or a local video file.

Install

git clone https://github.com/grimseal/video-to-article \
  ~/.claude/skills/video-to-article

Claude Code picks it up on the next session. There is no registration step.

Requirements

  • Python 3 — any version
  • ffmpeg (with ffprobe) on your PATH
winget install Python.Python.3 Gyan.FFmpeg      # Windows
brew install python ffmpeg                      # macOS
sudo apt install python3 ffmpeg                 # Debian/Ubuntu

yt-dlp and markdown install themselves on first use.

Use it

Just ask:

You
make a text version of this talk with the diagrams — https://youtube.com/watch?v=…

Claude reads the transcript, looks through contact sheets of the whole video to find the graphics, picks the frames, writes the article and renders the page. The skill tells it how.

What you end up with

my-article/ README.md the article index.html same article, clips playing inline images/ every diagram and chart clips/ short excerpts of the animated bits .vidnotes/ hidden: video, subtitles, transcript, working sheets

.vidnotes/ is where all the weight is, and nothing in the article links into it — delete it once you are done.

Driving the script yourself

fetchdownload the subtitles and video, write a timed transcript
sheetstile the whole video into contact sheets and print a tile → timestamp map
probetile specific timestamps side by side to pick the exact moment
framescut screenshots from a TIME|name list
clipscut excerpts from a START|DURATION|name list
htmlrender the Markdown into a page with inline video players
vidnotes.py fetch "<url>" --out my-article
vidnotes.py sheets --out my-article
vidnotes.py probe  --out my-article 93 1:36 2:56

Every command takes the same --out project directory. Timestamps accept 93, 1:33 or 0:01:33.

Why scan every frame

Picking timestamps from the subtitles alone does not work. Graphics routinely finish animating one to four seconds after the line that introduces them, and some appear with no narration at all.

So the skill tiles the whole video into contact sheets, has the model actually look at them, confirms the exact moment before cutting, and then checks its own work on another contact sheet afterwards.

About what you make with it

The article comes out written in the model's own words and restructured into sections — not a verbatim transcript. That is both the better read and the right call on someone else's video. The raw transcript stays in .vidnotes/ if you want it.

If you publish the result anywhere, credit the source video and link it.
